# Architect A (fire-code expertise) - building official misapplied code on a 1984 renovation

## Case

- A small renovation of a 1984 building. The architect looked up the historical codes to understand how the building was originally built.
- The fire/building official, whose background was unknown to the architect, referenced the wrong code document and section, without understanding the distinction between two similar-sounding code publications (transcription of the names is garbled).
- When corrected with a specific code reference, the official's "eyes glazed over." The official then appeared to second-guess himself and over-read the surrounding context to justify the wrong interpretation. Quote: "That's an interpretation the coverage can make" (the architect says the code is explicitly clear).
- The "prior approved condition" rule allows maintenance without upgrading, but the official questioned the architect's reasoning.
- Architect's frustration: uncomfortable questioning an official's expertise, yet the behavior suggests limited code knowledge.

## Relevance

Another data point on code-interpretation inconsistency and on the social cost of challenging officials; supports a tool that cites exact code sections and prior approved conditions.
