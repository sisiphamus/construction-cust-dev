# Permitter A (independent, Las Vegas) - jurisdiction layers, civil vs building, relationships

## Two tracks
- Building side (anything constructed from the ground up): the nation largely uses the same model codes (building, plumbing, mechanical, fire); the difference is which edition each jurisdiction has adopted, plus local administrative rules (life safety, signage, colors).
- Civil side (roads, sidewalks, bridges, tunnels, right-of-way): governed by local and state standards (state DOT, regional transportation commission details), not the model building codes. Civil plans are typically easier to read.
- Separate reviewers, separate comment cycles, separate code sets. A city like Houston has both.

## Jurisdiction layers
- Local, state, federal; state trumps local; submit to all applicable. Federal (aviation authority, land management, railroads) overrides everything when near airspace, federal land or rail. Dual jurisdiction "gets crazy": e.g., a sidewalk that was both city right-of-way and airport property.
- Within one metro, several jurisdictions each on a slightly different code year.

## Comments are universal
- She has never submitted without a comment. Some are legitimate (wrong code year on drawings, missing structural memos, unsigned stamps, one-line diagram errors). Some have nothing to do with code: a state highway renamed so the application's old name needs revision; civil stationing errors (plans read east to west; the point of intersection anchors the stationing).
- Non-code comments can be pushed back on: "Just because somebody tells you to do something doesn't mean you necessarily have to do it."

## Relationships as an edge
- After a few submissions to a jurisdiction you learn reviewers' personalities and what they flag. She builds personal rapport, which pays off when she needs a favor (push something through), but you earn it by never wasting their time. Submitting an incomplete package wastes everyone's time.

## Researching a new jurisdiction
- Start with the jurisdiction's website (forms, code years, requirements), then call or visit and ask for the intake reviewer (accepts applications) and the plan reviewer (reviews trade drawings). They are generally happy to walk you through it.

## Takeaway
- Even experienced permitters always get comments, which supports an error-check value proposition. Offered to continue the conversation later that day.
