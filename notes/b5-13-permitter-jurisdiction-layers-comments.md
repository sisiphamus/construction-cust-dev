# Permitter A (Las Vegas independent permitter) - jurisdiction layers and why comments never stop

## Two tracks
- **Building side**: ground-up construction. The nation follows the same model codes (IBC, plumbing, mechanical, NFPA); the difference is which code year a jurisdiction has adopted, plus local administrative rules (life safety, signage placement, building colors).
- **Civil side**: roads, sidewalks, bridges, tunnels, right-of-way. Governed by local and state standards (state DOT, regional transportation details), not the IBC family. Civil plans are typically easier to read than building plans.
- Separate tracks mean separate reviewers, comment cycles and code sets. Houston has both.

## Jurisdiction layers
Local, state and federal, with state trumping local; you submit to all that apply. Federal bodies (aviation, land management, railroads) override everything near airspace, federal land or rail. Dual jurisdiction "gets crazy": e.g. a sidewalk that was both city right-of-way and aviation department property. Within one metro, neighboring jurisdictions can sit on slightly different code years.

## Why you always get comments
She has never submitted without a comment. Some are legitimate (wrong code year, missing structural memos, unsigned stamps, one-line diagram errors). Others have nothing to do with code: a state highway renamed so your application has the old name; wrong point of intersection leading to wrong stationing (civil is read east to west). Non-code comments are pushback-able: "Just because somebody tells you to do something doesn't mean you necessarily have to do it."

## Relationships as an edge
After submitting to a jurisdiction a few times you learn reviewers' personalities and what they flag. Personal rapport earns goodwill for favors (faster push), but only if you never waste their time; an incomplete package wastes both sides' time.

## Researching a new jurisdiction
Start with the jurisdiction's website, which lists forms, code years and submission requirements. Then call or visit and ask for the intake reviewer (accepts applications) and the plan reviewer (reviews trade drawings); they are generally happy to walk you through.
